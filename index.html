ANTES DE COMEÇAR

Boas perguntas.
Novas possibilidades.

Preciso ter um arquivo 3D pronto?

Não precisa ter um arquivo para iniciar a conversa. Envie sua ideia ou referências para avaliarmos o que é necessário para o projeto.

Quanto custa uma impressão 3D?

O valor depende de fatores como tamanho, material, complexidade e quantidade. Envie os detalhes para receber um orçamento para sua peça.

Qual é o prazo de produção?

O prazo é combinado no orçamento, de acordo com o projeto e a disponibilidade de produção.

Vocês enviam para minha cidade?

Sim! Enviamos para todo o Brasil. Informe o CEP para consultar as condições de frete e o prazo de entrega no orçamento.
